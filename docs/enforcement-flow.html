Policy 2.0.0 — what changed

Plugin no longer hard-denies gh gist edit, python, or normal edits. Only credential regex matches hard-stop. Missing workflow now gives policy-gate: select_workflow … until you pick one, then defers to the native prompt.

How a Gist edit flows now

select_workflow(doc-maintenance) → draft /tmp/…/note.md → gh gist edit. Checkpoint 1 shows ASK, Checkpoint 2 sees workflow set and defers to same ASK. You Allow once, it runs, verified, then finish_workflow.

What stays hard

Credential files only: .env (except .env.example), .npmrc, .netrc, keys, *.pem, credentials*.json, .docker/config.json, .config/gh/hosts.yml. No prompt, by design. Use env vars or pydantic-settings.
