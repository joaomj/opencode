Enforcement Flow — Same input, same result. No AI judgment.

Three deterministic checkpoints. Scope: one agent action (file edit, bash, or gh gist edit) in a selected workflow. Hover any card for plain terms.

Hard stop: only credential paths (.env etc.) Ask: everything else Restart or /reload to load new rules
Allow — proceeds Ask — prompt to you Hard stop — no prompt Deterministic gate — same result every time
Before the fix

Gist draft and gh gist edit were blocked with no prompt, even though you wanted them. The front door and the guard both hard-denied.

After the fix

The same Gist sequence now shows a prompt at Checkpoint 1 and soft-defers at Checkpoint 2. Approve once and it runs and verifies.

What stays hard

Credential files only: .env, keys, tokens. No prompt, by design.
