description: Record a medium or high complexity bug fix postmortem
---

Use the `write-postmortem` skill to record `$ARGUMENTS`.

1. Confirm that the bug fix is medium or high complexity, or a significant incident.
2. Read the diagnosis, root cause, regression test, fix, and verification evidence.
3. Ask for missing facts. Do not invent impact, timeline, or prevention actions.
4. Select the standard or full postmortem tier using the skill's criteria.
5. Show the completed record to the user before treating it as final.
6. Do not commit or create a pull request unless the user explicitly requests it.
